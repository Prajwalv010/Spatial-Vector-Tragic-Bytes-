System Information

🎯 What is SpatialVector-HMI? A wearable assistive vision system providing real-time trajectory prediction and 2-motor vibro-tactile collision avoidance for visually impaired users.
🔒 What is "Local Edge Connected"? AI object detection, velocity estimation, and collision prediction run 100% locally on your computer/edge hardware. Zero cloud latency and 100% video privacy.
⚡ Hardware Architecture 2-Motor Chest Unit (Pin 5 Left, Pin 6 Right) driven via Arduino micro-controller, powered continuously via external USB PowerBank.
⏱️ TTC & CPA Metrics TTC (Time to Collision): Seconds until potential impact.
CPA (Closest Point of Approach): Closest estimated pass distance in meters.
